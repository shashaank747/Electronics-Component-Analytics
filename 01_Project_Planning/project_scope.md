# Project Scope

## Scope Matrix

| Included in Scope | Excluded from Initial Scope |
| :--- | :--- |
| **Inventory Analytics** | Complete ERP software implementation |
| **Procurement Analytics** | Live purchase order processing |
| **Stock Monitoring** | Live warehouse / WMS integration |
| **Supplier Comparison** | IoT sensor / RFID integration |
| **Inventory Valuation** | Production scheduling |
| **Monthly Stock Analysis** | Manufacturing defect analysis |
| **Interactive Power BI Reports** | Machine-learning demand forecasting |

## Scope Boundaries & Conventions
- **Synthetic Data**: All records are generated from scratch for this simulation. No real company or academic institution data is used.
- **Currency**: Indian Rupee (INR - ₹).
- **Unit of Measurement**: Standardized to **Piece** across all components to ensure aggregated stock quantities remain meaningful.
